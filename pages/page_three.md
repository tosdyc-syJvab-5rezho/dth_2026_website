# CLARIN SOFTWARE CASE 
## Virtual Language Observatory

The Virtual Language Observatory (VLO) is an online tool developed by CLARIN ERIC (Common Language Resources and Technology Infrastructure). It provides researchers in the humanities ans social sciences with access to digital languages resources, sucj as text colelctions, speech corpora and language tools. Users can search and filter these sources by language or type.

VLO could be useful for finding multilangual research material. For example, a student studying how migration is discussed across European countries could use it to find text collections in different languages ad compare how migration and cultural diversity are discussed in different languages and social contexts.
