# CLARIN SOFTWARE CASE 
## Virtual Language Observatory

The Virtual Language Observatory (VLO) is an online tool developed by CLARIN ERIC (Common Language Resources and Technology Infrastructure). It provides researchers in the humanities and social sciences with access to digital languages resources, such as text collections, speech corpora and language tools. Users can search and filter these sources by language, type or other categories, making it easier to find material for their research.

VLO could be also useful for finding multilangual research material. For example, a student studying how migration is discussed across European countries could use it to find text collections in different languages ad compare how migration and cultural diversity are discussed in different languages and social contexts. This would make it easier to find existing reaserch material without having to collect all the data from scratch.
